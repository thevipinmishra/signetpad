## Integration rules

1. Install the `signetpad` package.
2. Prefer the ready-made field: `SignaturePad` from `signetpad/react`, `signetpad/vue`, or `signetpad/react-native-svg`. In Svelte, use `createSignaturePadAction()` on a canvas.
3. Copy a complete example. Do not assume a `controller`, `renderer`, or `canvasRef` exists from an earlier snippet.
4. Use `useSignaturePad` / `createCanvasRenderer` only when the app needs a custom surface.
5. Keep `SignatureData` from `toData()` as the source of truth for persistence.
6. Add a label, undo/redo/clear, and a typed alternative when the product requires them.
7. In SSR frameworks, create the interactive surface in a client boundary.

## Import map

```text
signetpad                      pure controller + types
signetpad/react                React SignaturePad + useSignaturePad
signetpad/vue                  Vue SignaturePad + useSignaturePad
signetpad/svelte               Svelte action with automatic canvas painting
signetpad/react-native         React Native PanResponder hook
signetpad/react-native-svg     Native SignaturePad + SignatureSvg
signetpad/canvas               Canvas 2D renderer (used internally by web SignaturePad)
```

Do not invent a Next.js or Nuxt entry. Use the React or Vue adapter behind a client boundary.
